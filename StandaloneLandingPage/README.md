# Standalone landing page

Serve this folder with a local web server (for example, run `python3 -m http.server 8000` from this folder, then open `http://localhost:8000`). WebGL image textures may be blocked when opening the file directly. The folder is self-contained and can be zipped for the developer. This is an initial visual pass, not a final WordPress integration.

The supplied 3918 × 5766 JPEG is drawn as the poster, with the logos and caption separate and fixed to the viewport. A full-device-resolution WebGL canvas uses the cloud map from the previous audio experiment to push the JPEG outward from the centre of the headline. The first track attempts to play muted on load; if the browser blocks muted autoplay, playback starts after an interaction. Each press of Next advances to the next track, and Mute/Unmute controls both the sound and the distortion. Tracks also advance when finished. The bass response adapts to each track's level so the threshold works across different recordings. Edit the `playlist` array in `app.js` to add audio files and their artist and title. The test panel allows selection of a local audio file and adjustment of volume, effect strength and threshold. The artwork is flat, so all parts of the JPEG distort together. On devices with a smaller maximum texture size, the WebGL texture is scaled down to fit the device.

The signup uses the supplied test Mailchimp audience and its spam-protection field. With JavaScript enabled, it submits via Mailchimp's JSONP endpoint and shows an inline thank-you only on a successful response; without JavaScript, the form submits to Mailchimp's hosted page. Add `hidden` to the `signup-form` element in `index.html` to turn the signup off; remove `hidden` to show it. Before launch, replace the test form action and spam-protection field with those from the production audience's generated embed, incorporate any required fields, consent and other behaviour, and check the production plan's Mailchimp branding requirements. Test a real subscription, errors and confirmation on staging. The final ticket link is not yet configured. Test the eventual deployment on the target host, including font and asset paths, mobile sizing and the form.
