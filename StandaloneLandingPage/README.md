# Standalone landing page

Serve this folder with a local web server (for example, run `python3 -m http.server 8000` from this folder, then open `http://localhost:8000`). WebGL image textures may be blocked when opening the file directly. The folder is self-contained and can be zipped for the developer. This is an initial visual pass, not a final WordPress integration.

The supplied 3918 × 5766 JPEG is drawn as the poster, with the logos and caption separate and fixed to the viewport. When audio plays, a full-device-resolution WebGL canvas uses the cloud map from the previous audio experiment to push the JPEG outward from the centre of the headline. The test panel allows selection of a local audio file and adjustment of volume, effect strength and threshold. The bundled sample is for testing; replace it for the final page. The artwork is flat, so all parts of the JPEG distort together. On devices with a smaller maximum texture size, the WebGL texture is scaled down to fit the device.

The signup is a visual prototype and does not subscribe anyone yet. Add `hidden` to the `signup-form` element in `index.html` to turn it off; remove `hidden` to show it. To connect it, obtain the Mailchimp-generated embed for the correct audience, add its form action to `data-mailchimp-action` on that element, and add any required fields, consent, hidden fields and other behaviour from the generated embed. Test a real subscription and confirmation on staging. The final ticket link is not yet configured. Test the eventual deployment on the target host, including font and asset paths, mobile sizing and the form.
